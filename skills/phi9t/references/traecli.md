# TRAE CLI adapter

Use the active session's native tools. When invoking the CLI, inspect installed
traecli --help and the chosen subcommand's --help before choosing flags. Model
names and permission options are discovered runtime capabilities. Inherit the
configured model by default; preserve the user's selected sandbox and authority.

Install native skill directories into a root the active runtime discovers.
The historical phi9t install used ~/.agents. Validate discovery in a fresh
session before retiring the old installation. The file installer proves package
integrity, not that every TRAE version discovers that root. If a build only
supports flat skill files, retain complete relative resources through an owned
adapter instead of copying SKILL.md alone. Report unsupported discovery explicitly.

This stack supplies no fabricated CLI commands, automatic permission bypass,
model routing daemon or session-start hook. Native skills and capability-based
tool selection are the integration. A rejected model selection is a capability
failure: choose a permitted configured alternative, or reduce the comparison and
report the missing independent perspective.
