# Verification packet shape

A small SKILL.md explains the supported operation and points to detailed journeys
only when needed. A behavior map entry records:

- user goal and public entrypoint;
- starting fixture, candidate selection and runtime prerequisites;
- action and expected observable output;
- meaningful refusal and forbidden side effects;
- evidence location, cleanup and known coverage limits.

Keep stable recipes separate from dated run receipts. Each receipt records the
actual identity, command, result and qualification. A document linking to tests
is not a claim that those tests ran. A recipe copied from another host needs
qualification at the selected host and source state.
