# Triage labels

For this local tracker, labels are values of the `Status:` field.

| Role | Status | Meaning |
| --- | --- | --- |
| needs-triage | needs-triage | Needs maintainer evaluation |
| needs-info | needs-info | Needs more information |
| ready-for-agent | ready-for-agent | Specified and ready for an agent |
| ready-for-human | ready-for-human | Requires human implementation |
| wontfix | wontfix | Will not be actioned |

Use these exact strings when an engineering skill assigns a triage role.
