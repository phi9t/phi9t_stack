# 0.1.0-rc.6

First public prerelease. The bundle ships the fifteen phi9t method packages with
two vendored skill packages:

- `phi9t-pstack`: upstream pstack 0.15.43 (`93b916d`, cursor/plugins) with
  poteto-mode, its sibling skills (`how`, `why`, `swarm`, `interrogate`,
  `architect`, `unslop`, `tdd` and others), all principle skills, the
  poteto-agent definition, `no-comments`, and `create-verification-skill` and
  `maintain-verification-skill` for feature-map verification. The package router
  maps Cursor runtime terms (`Task`, `AskQuestion`, `cursor-team-kit`) to other
  agent runtimes.
- `phi9t-pocock`: Matt Pocock's skills 1.3.2 (`5863806`), `engineering` and
  `productivity` buckets, without frozen, deprecated or in-progress skills.
- `vendor.json` pins sources and file hashes; `scripts/vendor.py check` joins the
  source gate and refuses edited vendored files.

Runtime discovery of the nested skills is not yet verified on every agent host.
This remains a prerelease; preparation does not publish, tag or install globally.
