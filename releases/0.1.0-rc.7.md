# 0.1.0-rc.7

Publish the current shared stack after the first public prerelease. The catalog
contains fifteen native phi9t methods, pstack 0.15.43 pinned at `93b916d`, and
Matt Pocock's skills 1.3.2 pinned at `5863806`.

Changes since rc.6:

- Release tests build a small native-package fixture instead of depending on
  historical release notes or copying the full vendor catalog.
- Tests isolate global Git configuration, use process handshakes, exercise real
  filesystem recovery faults, and keep repository fixtures outside the checkout.
- Vendor synchronization stages the complete package before replacement and
  preserves the package and manifest when an include, patch or notice refuses.

Use the qualified release archive and its recorded SHA-256 for rollout. Install
with the bundled `scripts/stack.py` into an explicit agent root, then run
`verify` against that same root. Codex and TRAE can share `~/.agents`; Claude
Code uses `~/.claude`. Keep each changed installation's backup identity. Refresh
or start a new session after installation and check actual runtime discovery.
Existing skill enablement and unrelated customizations remain user-owned.

This remains a prerelease. Package checks and archive qualification do not prove
all method behavior, all nested-skill discovery, every runtime version, or other
platforms. The proposed router/worker-role redesign remains separate research;
this release does not adopt unimplemented proposals. Exact source, archive,
qualification and rollout evidence are recorded separately from this frozen
release input.
